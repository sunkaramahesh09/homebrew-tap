# homebrew-tap

Homebrew tap for [AirBridge](https://github.com/sunkaramahesh09/airbridge) — a native AirDrop ↔ Quick Share bridge for macOS and Android.

## Install

```sh
brew install sunkaramahesh09/tap/airbridge
```

This downloads a prebuilt universal macOS binary from the
[airbridge releases](https://github.com/sunkaramahesh09/airbridge/releases) page — no Rust toolchain required.

## Start the service

```sh
brew services start airbridge
```

## Update

```sh
brew upgrade airbridge
```
